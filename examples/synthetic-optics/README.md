# 合成光学机构演示

本示例使用两份明确标识为SYNTHETIC的虚构权利要求：A通过可转动的调焦环保持镜片，B通过弹性夹持件保持镜片。它展示怎样保存结构、条件、术语、关系与原文证据，不作性能排序或历史继承判断。

## 运行

只需Python 3.10或更高版本，无额外Python依赖、账号、网络或模型API。在仓库根目录执行：

```bash
python examples/synthetic-optics/generate_demo.py --output work/synthetic-demo
```

在浏览器打开 `work/synthetic-demo/report/index.html`。重复运行请换用新输出目录，避免覆盖已有记录。

## 可以检查什么

- 三角色共用同一条核心发现，分别解释其意义。
- 问题、术语、结构比较与两端关系能够连接到同件、同版本的原文。
- 已披露结构与未披露性能分别记录，主项和从属项条件不混用。
- 部分完成会阻止正式验收；补入固定审阅夹具并显式重导已回答后，才能生成报告。
- 报告可以离线打开，移动整个报告目录后，相对资产链接仍有效。

## 审阅记录的边界

`fixture.json`中的分析与审阅都是为复现软件行为而明确构造的测试夹具。演示脚本没有调用审查模型，也没有执行新的一次独立阅读；其中的 `independent:true` 是测试输入，不是对真实人员、模型行为或研究准确率的证明。

脚本根据本次测试库版本建立夹具的校验绑定，目的是测试数据接口。真实研究中不得这样自动填充审阅记录，也不得给旧结论换新指纹；必须由实际不同的负责者回到原文并记录自己的判断。

目录内不含真实企业、真实专利原件、数据库账号或个人密钥。合成公开号和主体仅用于测试身份字段，不能作为外部检索或法律判断的依据。

更多验证与限制见[验证记录](../../docs/validation.md)。
