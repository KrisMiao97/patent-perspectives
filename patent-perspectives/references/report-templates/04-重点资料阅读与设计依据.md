# 重点资料阅读与模板设计依据

阅读及编制日期：2026年11月17日。

本次重点阅读上次推荐的日本特许厅 IP Landscape 实践指南、GB/T 39551.5 研发活动标准和 EPO/IEA 电池报告，并补读企业经营、总则和服务要求标准、WIPO 报告编制指南的相关整章、WIPO 自由实施初筛工具及 Ernst 的原论文。下列记录说明实际阅读范围、可回查位置，以及原文怎样转化为模板。

三类模板的具体章节、填写表格、证据编号、预算分阶段安排和教学场景是本次设计，不是原机构发布的表格，也未经过真实企业项目效果验证。历史报告中的市场、主体排名与专利状态未被当作2026年的事实移植。

## 哪些阅读发现直接改变了模板

| 阅读所得 | 对原文的理解 | 本次转化为的模板内容 |
|---|---|---|
| JPO 第1—2章，目的先于方法 | 同一张专利分布图可以用于不同任务，方法应跟随具体问题选择 | 每部分先写“本节要决定什么”，再列证据；没有决策用途的统计不自动占正文篇幅 |
| JPO 第3章的三个虚拟案例 | 经营方向要通过市场、自身资源、竞争与合作条件的多轮比较形成 | 企业版设置备选进入方式、能力缺口、候选筛选理由与反对意见；不把专利量排名当最终建议 |
| GB/T 39551.5 §5—7 | 立项前要评价必要性和可行性；研发中要分析竞争、风险、方案优化及布局 | 研发版保留两种使用入口：立项审查与过程评审；技术路线之外还纳入需求、主体能力和验证条件 |
| EPO/IEA 第5、7章 | 主体的技术专长需要拆开看；材料性能和适用情境应一起解释 | 使用“企业×技术环节”矩阵和“路线×同工况指标”表；讲清结构与工作条件后再作比较 |
| EPO/IEA 方法与附录 | 专利族、时间字段、主体归并和分类规则直接影响统计含义 | 三份报告共用口径表；趋势图注明公开滞后；关键结论可回到清洗后数据及原文 |
| GB/T 39551.4 §9—11 | 产品开发可以选择自主开发、合作开发、技术引进；选择要符合企业实际 | 企业版和专利版均要求写明替代方案、依赖条件及退出条件，不只推荐一个方向 |
| WIPO 报告指南 §5.2、§8.7 | 应匹配受众与决策需要，并交付足以理解和复核的材料 | 三份摘要分别回答经营、研发、专利管理问题，但证据与版本保持一致 |
| WIPO FTO Tool 5 | 初步技术分析不能代替针对具体国家和设计的法律分析；主观匹配分数有严格用途边界 | 专利版逐项列出权利要求特征、产品对应证据、解释争议、状态及当地专业复核事项 |
| Ernst 第236—238页 | 商业视角的专利指标与法律判断有不同含义；组合图只提供部分决策信息 | 综合分值必须拆回指标和权重，另列关键权利核查；不能把高分写成可执行权利强或投资必然成功 |
| GB/T 39551.1 §7—9、39551.7 §6—7 | 报告应有方法、分析过程和建议，并关注运用与评价 | 设置证据附件、责任人、阶段交付与更新触发条件；服务验收不只看页数和检索数量 |

## 深读后的两项具体核查提醒

**统计原文也可能存在内部冲突。**EPO/IEA 报告第83页关于美国超级电容国际专利族份额的正文与表8.5分别出现18.2%和17.6%；关键页面图像已核对。本次不选择任一数字用于产品建议，而将其作为“正文与表格冲突时需要回查”的示例。真正的企业报告应登记冲突、核查分母和期间、联系数据来源，未解决前不据此排序。

**公司层级和产品层级不能自动互换。**JPO 案例提供了从候选长名单走向短名单的实用过程。迁移到企业项目时，需进一步确认目标市场的实际客户覆盖，以及拟合作或交易的具体业务是否拥有并能转移所需资源。总部所在地、集团总收入、其他部门的能力不能直接替代这些证据。
