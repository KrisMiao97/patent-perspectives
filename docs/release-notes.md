# 专利棱镜 2026.11.10-reader2

- 新增按材料研究。检索不可用时，用表格、号码清单、PDF 或可访问链接确认范围，冻结材料清单并核对来源。检索可用时，可补同件正文，保留原检索总数与分页校验。
- 新增读者设计规范和自包含 HTML 模板。三个角色在同一份报告中看结论、年度变化和原文，支持按章阅读、筛选工作台和主题索引。
